⚡ Deferrable Views (@defer)

Lazy load components for better performance

1. Defer on Viewport (Scroll Down)

Chart loads automatically when it enters the viewport

Scroll down to see the magic ↓
@defer (on viewport) { } @placeholder {
📊 Chart will load when you scroll here...
} @loading (minimum 500ms) {
Loading chart...
}

2. Defer on Interaction (Click Button)

Chart loads when you click the trigger button

@defer (on interaction) { } @placeholder {
} @loading {
Loading...
}

3. Defer on Hover

Chart loads when you hover over the placeholder

@defer (on hover) { } @placeholder {
👆 Hover over me to load chart
} @loading {
Loading...
}

4. Defer on Idle

Chart loads when browser is idle

@defer (on idle) { } @placeholder {
⏳ Will load when browser is idle...
} @loading {
Loading...
}

💡 Defer Triggers

  • on viewport - Loads when element enters viewport (Intersection Observer)
  • on interaction - Loads on click, focus, or touch
  • on hover - Loads when mouse hovers over element
  • on idle - Loads when browser is idle (requestIdleCallback)
  • on immediate - Loads immediately after rendering
  • on timer(ms) - Loads after specified delay
  • when (condition) - Loads when signal/expression becomes true

✨ Benefits

  • ✅ Faster initial load - Reduce bundle size
  • ✅ Better performance - Load heavy components only when needed
  • ✅ Improved UX - Show placeholders while loading
  • ✅ Automatic code splitting - Angular handles it for you
