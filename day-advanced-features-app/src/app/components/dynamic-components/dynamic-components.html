🎨 Dynamic Components

Create and render components programmatically at runtime

Total components created: {{ componentCount() }}

ℹ️ Components auto-remove after 5 seconds

💻 Implementation Example

// Component
@ViewChild('dynamicContainer', { read: ViewContainerRef })
container!: ViewContainerRef;

showSuccess(): void {
  // Create component dynamically
  const componentRef = this.container.createComponent(SuccessAlert);
  
  // Set component inputs
  componentRef.instance.title = 'Success!';
  componentRef.instance.message = 'Operation completed';
  
  // Auto-remove after 5 seconds
  setTimeout(() => componentRef.destroy(), 5000);
}

💡 Use Cases

  • Modals/Dialogs - Open dialogs dynamically
  • Toast Notifications - Show messages on the fly
  • Dynamic Forms - Build forms from configuration
  • Tab Content - Load tab content dynamically
  • Dashboard Widgets - Add/remove widgets at runtime

✨ Key APIs

  • ViewContainerRef - Container for dynamic views
  • createComponent() - Create component instance
  • ComponentRef - Reference to component instance
  • destroy() - Remove component from DOM
  • clear() - Remove all components from container
