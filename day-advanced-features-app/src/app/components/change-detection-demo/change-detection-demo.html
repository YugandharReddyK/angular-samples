🔄 Change Detection Strategies

Understanding Default vs OnPush

Default Strategy

Checks on every change detection cycle

OnPush Strategy

Only checks when inputs change (reference) or events fire

💡 Key Takeaways

  • Default: Checks component tree on every change detection cycle
  • OnPush: Only checks when @Input() reference changes or component events fire
  • Use OnPush for better performance with immutable data patterns
  • Signals work perfectly with OnPush - they create new references
